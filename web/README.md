# Site e API do ranking — pendentes

Esta pasta ainda não contém uma aplicação executável. Raiz prevista do projeto Vercel: web/.

Escopo inicial: site em pixel art com TOP 100 global, consulta de resultados, API HTTPS para registrar uma tentativa sem duplicatas e validação dos dados no servidor.

O jogo continuará com TOP 10 local, inclusive sem conexão. Envio global mediante confirmação do jogador; não exigir cadastro no primeiro protótipo. Três letras são apelido, sem exclusividade.

Dados mínimos planejados: identificador único da tentativa, apelido, quantidade de cenouras, vitória/derrota, versão do jogo e data atribuída pelo servidor.

Não colocar credenciais administrativas do Supabase no cliente web, no jogo ou no repositório. A proteção do endpoint e o modelo de validação serão definidos junto da implementação, antes de habilitar envios públicos.
