# Instruções do repositório

- game/ contém o jogo Godot; leia também game/AGENTS.md, README.md, ROADMAP.md e documentação de testes antes de alterar o jogo.
- Preserve os originais de game/assets/references/ e as regras de gameplay.
- web/ e supabase/ ficam separados da importação Godot; ranking global é o escopo adicional autorizado pelo usuário.
- Não usar comandos Git no PowerShell. Use o conector GitHub ou Git diretamente pelo cmd.exe.
- Não versionar credenciais, chaves, APKs, engines, SDKs nem caches. Exemplos de ambiente devem conter apenas valores fictícios.
- Não declarar integração online, publicação ou testes como concluídos sem verificá-los.
