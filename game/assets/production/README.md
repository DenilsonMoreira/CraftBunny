# Assets de produção — Craft Bunny

Esta pasta contém apenas arte técnica derivada das referências. Os arquivos originais permanecem intactos em `assets/references/`.

## Ordem de preparação do M5

1. `characters/bunny/`: coelho aprovado, sem roupas, com lenço vermelho gasto, bolsa lateral e martelo.
2. `enemies/`: cobra, guaxinim e ave de rapina.
3. `tiles/`: chão sólido separado de folhagens decorativas.
4. `items/`: cenoura, madeira e coração.
5. `ui/`: elementos sem textos incorporados quando possível.

As folhas atuais são concept sheets compostas e não devem ser atribuídas diretamente a `AnimatedSprite2D` ou `TileSet`. Cada recorte precisa ter fundo transparente real, pivô alinhado e dimensões consistentes antes de entrar no jogo.
